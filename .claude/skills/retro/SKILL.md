# Retro

1. **Status at handoff** (project `CLAUDE.md`): what is live, scores, what's confirmed in the real world and by what
   evidence, what's unproven, open decisions for Zack, and the next step. Newest first, short.
2. **Known lessons** (project `CLAUDE.md`): each root cause found this round, as a rule a future session can follow, with
   its origin (round, file).
3. **Lessons that travel:** if a lesson would help any project, add it to the studio repo's `LEAD.md` section 8 (one or two
   lines, with origin) and commit there. If the studio repo isn't attached to this session, list it in your final message
   under "Promote to studio".
4. **Agents, skills, templates:** if the loop itself was weak this round (an agent prompt kept missing something, a
   check-in caught something late), propose the fix to the studio files, not just to this project.
5. Commit and push. Tell Zack in two or three lines what changed in how we work, if anything did.
